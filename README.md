# ระบบคลินิก Offline

โปรแกรมบริหารคลินิกเวชกรรมขนาดเล็ก สำหรับคอมพิวเตอร์ 2 เครื่องในคลินิก (หน้าร้าน + ห้องตรวจ) ใช้งานประจำวันโดยไม่ต้องมีอินเทอร์เน็ต ไม่มีค่ารายเดือน

เหมาะกับคลินิกแพทย์ 1 คน รับเงินสดหรือโอน **ไม่รองรับการเบิกประกันสังคม/บัตรทอง หลายสาขา หรือการทำงานบนคลาวด์** เริ่มด้วยชุดทดลองและข้อมูลสมมติก่อนเสมอ

## ดาวน์โหลดและเริ่มใช้

ต้องใช้ **Windows 10/11** และ Microsoft Edge เครื่องห้องตรวจต่อเครือข่ายส่วนตัวเดียวกับหน้าร้าน อินเทอร์เน็ตใช้ตอนดาวน์โหลด อัปเดต หรือส่งสำเนาเข้ารหัสขึ้นคลาวด์เท่านั้น

เปิด [หน้าดาวน์โหลดรุ่นล่าสุดที่ mk-artifacts](https://github.com/mkungsuki/mk-artifacts/releases/latest) แล้วเลือก:

- **ClinicTrial-…zip** — ชุดทดลอง มีข้อมูลสมมติ ใช้ฝึก ห้ามใส่ข้อมูลคนไข้จริง
- **ClinicSetup-…zip** — ชุดติดตั้งใช้งานจริง ฐานข้อมูลเริ่มว่าง

ทั้งสองชุดมี Node.js พกพาในตัว ขนาดโดยประมาณ 35–50 MB ไม่ต้องติดตั้งเครื่องมือเขียนโปรแกรม

> ตรวจหน้าสาธารณะเมื่อ 16 กันยายน 2569: รุ่นล่าสุด 1.0.6 มีชุดติดตั้ง ClinicTrial และ ClinicSetup แล้ว เลขรุ่นและวันที่ท้ายชื่อไฟล์จะเปลี่ยนเมื่อเผยแพร่รุ่นใหม่ หากไม่พบไฟล์สองประเภทนี้ ให้หยุดและสอบถามผู้ดูแล

### โหลดครั้งแรก ทำตามนี้

1. กดลิงก์หน้าดาวน์โหลดรุ่นล่าสุดด้านบน ไม่ต้องสมัครบัญชี GitHub
2. เลื่อนลงไปที่ **Assets** (รายการไฟล์) ถ้าพับอยู่ให้กดเปิด
3. สำหรับฝึก เลือกไฟล์ **ClinicTrial-…zip** เพียงไฟล์เดียว; เมื่อตั้งใจเริ่มใช้งานจริงจึงเลือก **ClinicSetup-…zip**
4. รอโหลดเสร็จ ใน Edge กด **Ctrl+J** แล้วกดไอคอนโฟลเดอร์ / **แสดงในโฟลเดอร์** ของไฟล์ที่เพิ่งโหลด
5. คลิกขวา ZIP → **แยกทั้งหมด (Extract All)** → เปิดโฟลเดอร์ที่แตกแล้ว → ทำตามคู่มือติดตั้ง

**อย่ากด Code → Download ZIP หรือ Source code** เพราะเป็นไฟล์สำหรับผู้พัฒนา ส่วน **ClinicApp-…zip / .json / .sig** เป็นไฟล์ที่ระบบอัปเดตใช้ ไม่ใช่ตัวติดตั้งเครื่องใหม่ หากเบราว์เซอร์ขึ้นคำเตือน ให้ตรวจข้อความและแหล่งที่มาก่อน ไม่ปิดระบบป้องกันหรือกดผ่านทุกคำเตือน

อ่าน [คู่มือติดตั้งและหน้าร้าน](docs/คู่มือฉบับเต็ม-สำหรับหน้าร้านและผู้ดูแล.md) · [คู่มือแพทย์](docs/คู่มือฉบับเต็ม-สำหรับหมอ.md) · [แบบทดลอง](docs/แบบทดลองใช้-สำหรับหมอ.md)

**SmartScreen:** โปรแกรมไม่ได้ซื้อใบรับรองผู้เผยแพร่สำหรับ Windows จึงอาจขึ้นคำเตือน “Windows protected your PC” กด **ข้อมูลเพิ่มเติม (More info) → เรียกใช้ต่อไป (Run anyway)** เฉพาะไฟล์ที่ได้จากหน้าดาวน์โหลดทางการด้านบนและตรวจชื่อไฟล์แล้วเท่านั้น หากแหล่งที่มาไม่แน่ใจ ให้หยุด ไม่ต้องปิดระบบป้องกันไวรัส

## ทำอะไรได้บ้าง

คิวหน้าร้านและห้องตรวจ เวชระเบียน สั่งยาด้วยตารางมื้อยา (dose grid) สต็อกยาและ LOT/วันหมดอายุ รับเงินและใบเสร็จ ใบรับรองแพทย์รวมแบบใบขับขี่ ใบนัด ปฏิทิน และรายงาน

สำรองข้อมูลเข้ารหัส กู้ด้วย Recovery Kit และตรวจลายเซ็นดิจิทัลก่อนติดตั้งรุ่นใหม่ ผู้ดูแลเป็นผู้ยืนยันอัปเดต

ภาพต่อไปนี้สร้างจาก `seed-mock-clinic.js` ในฐานข้อมูลชั่วคราว ทุกชื่อและรายการเป็นข้อมูลสมมติ:

## ข้อมูลและการรับผิดชอบ

ฐานข้อมูลอยู่ที่เครื่องหน้าร้าน เครื่องห้องตรวจเชื่อมผ่าน HTTPS ภายในคลินิก ผู้พัฒนาไม่มีช่องทางเข้าดูคนไข้ ไม่มีระบบส่งสถิติการใช้งานกลับผู้พัฒนา (telemetry) หากคลินิกตั้งสำรองขึ้น Google Drive/OneDrive จะส่งเฉพาะไฟล์สำรองเข้ารหัสผ่านบัญชีของคลินิกเอง

**กุญแจกู้เป็นของคลินิก หากกุญแจหายและไม่มี Recovery Kit ที่ใช้ได้ ผู้พัฒนากู้ข้อมูลเข้ารหัสให้ไม่ได้** เก็บชุดกู้แยกจากคอมพิวเตอร์และ USB สำรอง ทำ checklist ส่วน E และซ้อมกู้ให้ครบก่อนใช้ข้อมูลจริง

ซอฟต์แวร์แจกตามสภาพ ไม่มีการรับประกัน ตามขอบเขตที่กฎหมายอนุญาตใน [LICENSE ข้อ 15–16](LICENSE) คลินิกมีหน้าที่ในฐานะผู้ควบคุมข้อมูลส่วนบุคคลตาม PDPA และต้องจัดการสิทธิ์ การเก็บรักษา และความปลอดภัยของข้อมูลตนเอง

โปรแกรมนี้ใช้จัดการงานและเอกสารคลินิก ไม่ใช่เครื่องมือวินิจฉัยหรือรักษาโรค ไม่ทดแทนดุลยพินิจแพทย์ และไม่ใช่การรับรองสถานะเครื่องมือแพทย์ตามกฎหมาย ต้องทวนยา ขนาดยา และเอกสารก่อนใช้จริง
