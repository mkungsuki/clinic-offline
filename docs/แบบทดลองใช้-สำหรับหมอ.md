## วิธีเริ่ม

1. เปิดไอคอน **ระบบคลินิก (ทดลอง)** ต้องเห็นแถบเหลืองว่ามีข้อมูลตัวอย่าง
2. ใช้ข้อมูลสมมติเท่านั้น ห้ามกรอกชื่อหรือข้อมูลคนไข้จริง
3. ใช้บัญชีตามช่วง: front/front123, doctor/doctor123, admin/admin1234
4. หลังแต่ละข้อ ติ๊กความรู้สึกทันที ไม่ต้องเขียนสวย
5. เล่นผิดได้ ข้อมูลเละได้ ชุดทดลองลบทิ้งและติดตั้งใหม่ได้

ถ้าจะทดลองการส่งคิวจริงระหว่างสองจอ ให้ติดตั้งที่เครื่องหน้าร้านเครื่องเดียว เข้าบัญชี admin → **ตั้งค่า** → การ์ด **เครื่องห้องตรวจ** → กด **ตั้งค่าเครื่องห้องตรวจ** เมื่อโปรแกรมรีสตาร์ทให้เข้า admin ใหม่ จากนั้นเอาโฟลเดอร์ **ส่งไปเครื่องหมอ** ไปที่เครื่องหมอ ติดตั้งใบรับรองหนึ่งครั้ง แล้วเปิดทางลัด **เปิดระบบคลินิก (ห้องหมอ)** ไม่ต้องติดตั้งโปรแกรมซ้ำ ทั้งสองเครื่องต้องอยู่ Wi-Fi/สาย LAN วงเดียวกันและเครื่องหน้าร้านต้องเปิดอยู่

ก่อนเริ่ม ให้ลองลงทะเบียนชื่อสมมติจากบัญชี front ที่เครื่องหน้าร้าน แล้วตรวจว่าชื่อเดียวกันปรากฏในคิวบัญชี doctor ที่เครื่องหมอ หากไม่ปรากฏ ให้หยุดจับเวลาและแก้การเชื่อมต่อก่อน
